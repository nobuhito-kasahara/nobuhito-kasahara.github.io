Bump Pie Menu

レイを引っ掛ける感覚を用いたVR円形メニュー

概要

レイ操作に手応えを与えるメタファを導入し、VR空間でのメニュー選択を高速かつ確実にすることを狙ったUI研究です。

研究背景

VR・AR等の3次元仮想環境では、コントローラや手が空中で自由に動くため、ターゲットを外れないよう腕を固定しながら選択動作を行う必要があり容易ではない。デスクトップのマウス操作は机という平面に支えられているため安定しており、この安定性のなさがVRでの選択を難しくしている。

2D GUIでは、画面角や画面端といったカーソル侵入不可領域に接するターゲットは高速かつ正確に選択できることが知られている（弾道運動による実質無限大ターゲット効果）。この利点を3次元に応用し、「レイを引っ掛ける」感覚で安定してターゲットを選択できる円形メニューを提案した。

手法・実装

Bump Pie Menuでは、3次元空間のメニュー平面に当たり判定付きの円形外壁と、選択領域を分割する円形の引っ掛かりを設置した。コントローラのレイはこのオブジェクトを通過するが、レイとメニュー平面の交点に表示されるカーソルが壁と衝突して凹みに留まる。ユーザはカーソルを目的の凹みへ向けて直線的に動かし、次いで引っ掛かりの角に向かって外壁を滑らせるだけでよく、選択動作を2段階に分けて行える。選択項目数は16個。

評価結果

既存手法Pie Menuと比較するユーザ実験（4名、男性2名・女性2名、640試行：16試行×10セット×4名）を実施した。エラー率の平均値は既存手法8.44%に対し提案手法2.03%と約4分の1に低下し、全参加者でエラー率が低下した。操作時間は既存手法1.23秒に対し提案手法1.33秒と約0.1秒増加したが、1名では逆に短縮された。レイの移動速度は提案手法の方が速く、タスク後半でも減速しないことから、コントローラを減速させずに選択できていることがわかった。

考察・今後

最初にレイの方向を間違えると別のターゲットに引っ掛かり修正が難しくなる点が課題として挙がった。引っ掛かりの大きさや形を動的に変化させる改善が考えられる。ハンドトラッキングや直接操作への展開、触覚フィードバックとの組み合わせ、視線ポインティングといったより不安定な操作手法への応用も今後の方向として考えている。
