Nobuhito Kasahara

笠原 暢仁

System Engineer at Sony Honda Mobility, IVI Systems Development Division

明治大学先端数理科学研究科先端メディアサイエンス専攻にて修士（理学）を取得。 HCI (Human-Computer Interaction) を専門とし、特にパフォーマンスモデルや、ユーザインタラクション、味覚メディア、XRに関する研究に従事。 現在は、ソニー・ホンダモビリティ株式会社 IVIシステム開発部 IVIシステム課にてシステムエンジニアとして勤務。

Research Interests

Performance Modeling

Fitts' LawやSteering Lawを用いたポインティング動作の操作時間予測モデル、およびDual Gaussian Distributionモデルを用いたポインティング成功率予測モデルに関する研究。

UI & UX

より直感的で使いやすいUI、より快適なUXを目指す。特に、画面端・画面角における高速かつ正確なポインティングに着目した研究。

Virtual Reality

仮想現実環境におけるユーザインターフェースの設計と評価に関する研究。

Taste Media

味覚ディスプレイの拡張として、カトラリー型味覚提示デバイスによる個人の好みやコンテクストに対応可能な味覚体験の拡張と実装に関する研究。

Projects

Performance Modeling

GUI操作時のユーザのパフォーマンスを予測するモデルに関する研究。Fitts' Law、Steering Lawの拡張や、Dual Gaussian Distribution Modelを用いた画面端・画面角でのタップ成功率予測などを扱っています。

  • More

Taste/Olfactory Media

人間の味覚や嗅覚を拡張・制御する新しいインタフェースの提案。カトラリー型味覚ディスプレイ「TTTV4」や、飲料に香りを付与する嗅覚メディア「AromaSynth」、カカオの味の再現手法に関する研究を行っています。

  • More

UI & UX

新しいコンピュータ環境における直感的なインタフェースと操作体験に関する研究。指先の変形を活用したVRインタラクション、VR用円形メニュー「Bump Pie Menu」、ドローン操縦UIなどを扱っています。
